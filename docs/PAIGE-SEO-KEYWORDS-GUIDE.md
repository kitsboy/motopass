## Architecture

### Keyword Map (`seoKeywords.ts`)

```typescript
export const SEO_KEYWORDS: Record<LangCode, RouteSeoKeywords> = {
  en, es, fr, pt, zh, ar, sw, de, hi, ja,
}

// Each route has:
type SeoKeywords = {
  title: string       // ≤60 chars, optimized for search
  description: string // ≤160 chars, compelling meta
  keywords: string[]  // primary, secondary, long-tail
  h1: string          // main heading
}
```

### Integration with SeoHead

```typescript
// In resolveSeoForPath():
const kw = getSeoKeywords(pathname, lang)
return {
  title: kw.title || meta.title,
  description: kw.description || meta.description,
  path: pathname,
}
```

### Adding a New Language

1. Add the language to `languages.ts`
2. Add keyword entries to `seoKeywords.ts` for each route
3. The SeoHead component automatically generates hreflang for all languages
4. Update `public/sitemap.xml` with new hreflang alternates
5. Add translations to `translations.ts`

## Honesty Rules for Paige

1. **Never promise search rankings** — SEO improves discoverability, not guarantees.
2. **Keywords must match content** — titles and descriptions accurately reflect what's on the page.
3. **hreflang is machine-translated** — the actual page content may have less coverage than the meta tags suggest.
4. **Structured data is accurate** — GovernmentService schema reflects real program data, not marketing.
5. **The sitemap is static** — it needs manual updates when routes change.
6. **AI crawlers are welcome** — MotoPass wants to be found in AI search, not hidden from it.
7. **Long-tail keywords target real intent** — "satohash verified programs" matches users who know the tech.
8. **Social previews use the default hero image** — no per-page custom OG images yet.
